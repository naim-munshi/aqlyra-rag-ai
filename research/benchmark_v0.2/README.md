# Aqlyra Phase 3 Benchmark v0.2

This package is the development foundation for Phase 3: Research Benchmark & Dataset.

It deliberately does not lock the paper's research question. It defines the dataset, masking, and reproducibility contracts needed to test the current candidate phenomenon without turning the pilot into a novelty claim.

Primary external sources: BEIR, LoTTE, BRIGHT, DAPR, RRF, ACORN/FVS, and the 2026 partial embedding-migration study listed in the research review.
